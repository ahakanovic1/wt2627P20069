# EcoTrack – Web tehnologije, Spirala 2

## Struktura projekta

- `index.html` – glavna HTML stranica
- `css/stil.css` – CSS stilovi
- `js/` – evidencija mjerenja i povezivanje sa stranicom
- `slike/` – slike koje koristi stranica
- `ODLUKE-S1.md` i `ODLUKE-S2.md` – obrazloženja za spirale 1 i 2

Pokrenite lokalni server u glavnom folderu projekta i otvorite `index.html` preko adrese servera. JavaScript moduli ne moraju raditi ako se stranica otvori direktno preko `file://`.

Slike koje se koriste u projektu:
- `ecotrack-logo.png`
- `list-dekoracija.png`
- `zelena-munja.png`
- `zeleni-papiri.png`
- `eko-recikliranje.png`
- `zastavica-cilj.png`

Folder `slike/` treba sadržavati originalne PNG datoteke iz projekta.

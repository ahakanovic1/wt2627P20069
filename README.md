# EcoTrack – Web tehnologije, Spirala 1

## Struktura projekta

- `html/index.html` – glavna HTML stranica
- `css/stil.css` – CSS stilovi
- `slike/` – slike koje koristi stranica

Otvorite `html/index.html` u pregledniku. Relativne putanje do CSS-a i slika podešene su za ovu strukturu.

Slike koje se koriste u projektu:
- `ecotrack-logo.png`
- `list-dekoracija.png`
- `zelena-munja.png`
- `zeleni-papiri.png`
- `eko-recikliranje.png`
- `zastavica-cilj.png`

Folder `slike/` treba sadržavati originalne PNG datoteke iz projekta.
